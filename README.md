# Öğrenci Ders Programı Mobil Uygulaması

**Ders:** Mobil Programlama  
**Öğrenci:** Hussam Al Sleem  
**Öğrenci No:** 2210238518  
**Teknoloji:** React Native + Expo Router  

## Proje Açıklaması
Bu uygulama, öğrencilerin haftalık ders programlarını gün bazında filtreleyip listelemesi ve seçtikleri dersin detaylarını (saat, derslik, öğretim elemanı, kredi vb.) görüntülemesi için geliştirilmiştir.

## Özellikler
- **Ders Listesi:** En az 4 ders kaydı (data/courses.js), FlatList ve CourseCard bileşeni.
- **Gün Filtreleme:** Pazartesi, Salı, Çarşamba, Perşembe, Cuma günlerine göre filtreleme.
- **Dinamik Rota:** /ders/[id] sayfası, useLocalSearchParams ile dinamik ID alma.
- **Hata Yönetimi:** Bulunmayan bir ders ID'si girildiğinde kontrollü hata ekranı ve geri dönüş butonu.
